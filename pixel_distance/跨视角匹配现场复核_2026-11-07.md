# D04/D03 现场跨视角匹配复核

## 目标与样本

在 D04 主钩画面选择任意两点后，由其他同步视角自动找到同一物理点，再在有效的共同坐标系中分别三角化 A/B。本次检查 D04 原始帧中的 A `(624, 513)`、B `(647, 535)` 与 D03 同秒原始帧。两路画面都能看到悬挂工件，但可见同一物体不等于可见同一表面点；烧录到秒的时间也不能证明曝光同步。

车长约 4–5 米只用于离线诊断。旧演示位姿以车体红色端部标记和车长先验构造，**不是独立标定的运行时位姿**。正式 `auto-3d` 默认拒绝该状态。

## 复核结果

| 方法 | 本次观察 | A/B 局部结论 |
| --- | --- | --- |
| SIFT + 车长诊断位姿 | 两图有 13 组双向特征；0 组在 3 像素极线阈值内，最小极线误差 33.1 像素 | 两点均无合格跨视角对应，程序返回 `unknown` |
| SIFT 前 50 个描述子候选再做极线及双向检查 | 仅 1 组相互确认，且不在 A/B 附近 | 不能通过放宽全局描述子搜索建立点对应 |
| XFeat 稀疏匹配，960 像素宽 | 152 组初始匹配；按车长诊断位姿 0 组通过，最小误差 10.8 像素 | 无 A/B 邻域合格点 |
| XFeat 半稠密匹配，960 像素宽 | 210 组初始匹配；按车长诊断位姿 1 组通过，但距 A/B 超过 300 像素 | 无 A/B 邻域合格点 |
| XFeat 独立拟合极线几何 | 过滤文字和边框后约 15–21 个内点；检查图显示内点混有地面、设备和吊物 | 不能把这些内点视作同一静态地面或可靠的米制建系点 |
| XFeat 吊物区域裁剪及 0/90/180/270 度旋转 | 稀疏匹配 179–349 组；局部极线内点不能同时覆盖 A/B，原方向 A 最近内点约 41 像素且局部几何不一致，B 最近约 71 像素 | 不能可靠转移所选点 |
| Tiny RoMa 吊物区域裁剪 | A/B 置信度约 0/0.001，往返误差约 149/191 像素 | 模型给出的像素转移必须拒绝 |
| LoFTR，D04/D03 同秒原始帧 | 全图匹配可执行，但 A/B 附近缺少跨视角特征 | [独立复核结果](demo_output/D04_D03_吊物点_LoFTR_离线复核.json)返回 `unknown` |
| 已知位姿下的极线图像块匹配 | 合成双目图可恢复选点和米制距离；当前 D04/D03 使用车长诊断位姿校正后，A/B 图像块都落在无效区域 | [现场诊断结果](demo_output/D04_D03_吊物点_Patch_离线复核.json)返回 `unknown`；不能据此评估真实标定位姿 |

针对图像块方法又检查了双目校正的裁剪参数 `alpha=0/0.5/1`。车长诊断位姿下，D04 两个选点的校正后纵坐标分别约为 `2660–2733`、`3030–3049`、`3365–3400` 像素，全部位于 1080 像素高的输出画面之外；`alpha=0` 时两路校正有效 ROI 也均为空。故放宽局部相似度或改裁剪不能使该诊断位姿产生可信点对应。现场尚无实测 K、畸变和当帧 D04/D03 相对位姿文件，不能据这组名义数据评估实际匹配率或米制误差。

又以 D04 的 `(624,513)`、`(647,535)` 对 D03 同秒的两个相邻候选帧复核 XFeat，分别在 960 和 1920 像素宽运行，过滤时间文字及边框，再用 2 像素阈值拟合基础矩阵。四种组合各有 61–108 组候选、11–13 个极线内点；A/B 到最近内点仍相距约 85–157 像素。原分辨率增加了候选数，但没有给所选点提供局部对应支撑。四路同刻 XFeat [复核结果](demo_output/D04_吊物点_XFeat_四路复核.json)中，D01、D02、D03 均因极线内点不足而未匹配。这些计数来自本次诊断筛选，不等同于程序默认筛选后的计数，也不能作为测距精度指标。

另将 XFeat 的 8 像素网格稠密描述子用于 A/B 选点查询：在 960 像素宽图上，两点的最高余弦相似度分别约 0.701、0.727，候选分散在 D03 的多个区域；将各最佳候选反向查询，均未返回原选点附近。这个试验没有提供可接受的双向同名点，不能以最高相似度像素代替测量点。

XFeat 的[全图内点检查图](demo_output/D04_D03_xfeat_inliers.png)中，同样的时间文字叠加产生了跨相机“匹配”，并非车间物理点；[过滤文字后的检查图](demo_output/D04_D03_xfeat_masked_inliers.png)仍显示跨表面的混合对应。仅有一个基础矩阵的 RANSAC 内点数不能证明物理同名性，更不能证明米制测距精度。

从原视频逐帧比对确认，当前两张原始截图分别精确对应 D04 的第 `92550` 帧和 D03 的第 `38000` 帧。按叠字图样分段，仍显示 `15:57:32` 的 D04 帧约为 `92534–92557`，D03 为 `37989–38013`（两路均为 25 fps，边界受叠字压缩影响，作诊断近似）。在各自同秒的首末帧之间，用灰度角点的双向光流和 RANSAC 单应内点衡量静态背景运动：D04 为 345 个内点、原图尺度中位位移约 **34.0 像素**，D03 为 626 个内点、中位位移约 **0.1 像素**。因此同秒内 D04 机位明显变化；秒级叠字不能保证两路截图同一曝光时刻。光流像素位移不是米制位置误差，其影响还取决于真实相机位姿和目标运动。

上述结果不能单独判定失败完全来自匹配器还是车长诊断位姿误差。车长诊断位姿的相对朝向检查误差约 31 度，不能作为真实外参。不同视角可能看到吊物的不同表面；若所选实体点在另一视角被遮挡，仅靠图像匹配无解。

## 连续视频与固定相机组建图初筛

四路 MP4 各约 69 分钟，按文件名起始时间计算的共同覆盖时段约为 15:32–16:04，但文件名和帧序号不能直接当作曝光时间。按文件名取 15:42:00 附近画面时，D02 烧录时间为 15:41:55，D04 为 15:42:04；按画面文字修正到同秒后，D02/D04 有 30 组双向 SIFT 候选、18 组基础矩阵内点；XFeat 有 169 组候选、27 组内点。[同秒 SIFT 检查图](demo_output/D02_D04_1542_synced_sift_inliers.png)显示部分点集中于设备，但还有跨表面或疑似错配。秒级校正不能证明帧级同步。

对共同时间段约每 4 分钟取一组画面，XFeat 在固定组 D01/D03 中得到 14–26 个基础矩阵内点，在固定组 D02/D04 中得到 16–33 个；跨组 D04/D03 为约 14–18 个。[D02/D04 15:42 初筛图](demo_output/D02_D04_1542_xfeat_inliers.png)表明部分设备结构可匹配，但不能仅凭内点数量确定真实对应。按当前名义内参做 Essential Matrix 恢复时，D02/D04 八个抽样的相对旋转候选约在 1.8–114.3 度间变化；同秒 15:42 的 SIFT 候选约 174.7 度，和 XFeat 候选也不一致。两相机刚性安装，真实相对旋转不可能如此变化，因此这些候选**不能用于米制地图初始化**。广角畸变未标定、重复设备结构、跨表面错配和帧级时差均可能影响结果，现有数据不能把原因唯一归属给其中一项。

把 15:42 的 D02/D04 候选跨时刻连接到 D03 的 15:57:32 帧，XFeat 仅得到 16–18 个基础矩阵内点，[D04/D03 检查图](demo_output/D04_1542_D03_1557_xfeat_inliers.png)仍有跨表面连接，尚不足以对 D03 做可信 PnP 重定位。初始化视觉地图前应先校正内参/畸变、建立帧级共同时间轴，并要求同一固定相机对在多个车位恢复一致的相对姿态；地图点还须通过跨时间、跨视角重投影及独立长度检查。

## 实现状态与下一步

当前程序已支持在**已知共同世界位姿**时让 A、B 分别由不同辅助相机三角化，并拒绝相互矛盾的多视角三维点。现场 D04/D03 两点仍输出[不可判定结果](demo_output/D04_D03_吊物点多视角复核.json)，没有可验证的实际距离。

下一阶段先用实际内参、镜头畸变、组内固定基线和帧级曝光时间建立可验证的相机几何；若不提供大车与小车实时位置，应在静态车间结构上建立米制视觉地图，让两组相机分别定位到同一地图。地图/位姿须使用独立于拟合点的已知尺寸复核，且覆盖吊物所在的高度与深度。车长或其他独立长度可用于离线发现偏差，不能作为每次运行时的必需锚点，也不能由同一结果自我验证。若选点在其他视角不可见或无法确认同一表面特征，继续返回 `unknown`。
