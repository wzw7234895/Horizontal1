# 人员与工件同时移动：检测与跟踪如何选择

日期：2026-11-05。适用当前四路相机人员/吊物视觉方案。本说明依据现有 B5“人随吊物伴行”、B6/B10 空间覆盖等业务划分，说明所需最小时间信息；本次未修改检测算法、未训练模型。

## 1. 先明确要判定的事件

| 业务目标 | 所需信息 | 是否需要稳定人员 ID |
|---|---|---|
| 吊物正在移动时，指定风险区域内存在人员 | 吊物真实运动状态、每帧人员位置、区域关系、事件时间窗 | 不必长期保持个人身份；检测加区域事件状态即可作为第一版。 |
| 人员与工件都在实际移动，且移动时间重叠 | 上述目标的运动证据，例如相机运动补偿后的目标位移或 ROI 光流 | 不一定需要显式长时间 ID，但必须有跨帧运动估计；不能只判断有无人。 |
| 同一人员持续伴随同一吊物移动，即 B5 | 短时目标对应、人员与吊物的运动方向、相对位置变化、悬吊状态及持续时间 | 建议保持本相机、事件时间窗内的短时 ID/对应关系。 |

因此，若“同时移动”指 B5，建议保留人员和工件的**短时运动关联**。这不要求在整段录像、重新进场或不同相机间永久识别同一个人，也不要求新增 ReID 模型。

“有无人”不能证明人员在移动：同一个人站立不动、多个人交替出现，以及相机自身移动，都可能使跨帧人员检测结果变化。反之，跟随起重机一起移动的工件在相机画面中位置变化可能很小，也不能据此认定工件静止。

## 2. 针对 B5 的最小实现方案

1. **人员和工件定位。** 人员沿用 YOLO 检测。工件取得可靠检测/分割模型后使用其输出；当前无吊物训练标签时，可沿已有方案以运动补偿后的前景/光流生成候选，但须验证候选确为目标载荷及悬吊状态。
2. **估计相机运动。** D01/D03 随大车移动，D02/D04 随小车移动；利用静态背景、地面特征和标定，区分镜头自运动、目标平移、吊物摆动及升降。现有 BoT-SORT 的背景光流补偿有助于图像关联，但不是物理坐标或真实速度测量。
3. **保持短时对应。** 人员可继续使用已部署的 BoT-SORT，不启用 ReID；工件维护独立候选轨迹。只需覆盖用于判断伴行的事件时间窗及允许遮挡间隔；时间窗由运动速度、误报和允许告警时延决定。
4. **比较配对运动。** 对同一候选人员与同一载荷，检查载荷确实移动、人员确实移动、方向关系、相对位置是否满足业务约束，并确认持续时间。只要两者同时移动就报警，会把远处独立行走、横穿以及短暂同向运动混为伴行。
5. **维护事件状态。** 保存进入候选、确认事件、事件结束和证据不足状态，合并重复报警。遮挡期间缺少人员检测不等于人员已经离开，无法确认时保留不确定状态，避免因漏检直接解除风险。

第一版可以直接复用现有人员跟踪模块，增量重点是工件状态、相机运动和配对事件规则；不用先研发另一套长期人员身份模型。

## 3. 只做“移动吊物附近有人”时可以简化

如果业务规则只要求“吊物移动期间，风险区域里有任意人员就提示”，可以采用：

```text
吊物真实移动状态
        +
当前帧人员检测及位置
        +
风险区域关系
        ↓
区域事件的时序确认、告警去重和遮挡处理
```

此时事件可以按区域/吊物管理，不必知道区域内每次出现的是否为同一个人。这种规则通常比伴行判定宽泛：人员站立不动也可能触发，应作为不同告警语义配置，不能直接替代设计中的 B5。

如果需要 B1/B2 的**按个人停留计时**，或者需要区分谁进入、离开和持续停留，则仍需相应身份关联；“区域始终有人”和“某个人始终停留”也属于不同业务。

## 4. 对现有现场尤其需要注意的条件

- **人员静止时也存在空间风险。** B6 判断吊物下方是否有人，B10 判断移动吊物是否经过人员上方。人员站立时也应覆盖这些事件，不能把人员同时移动作为这两项能力的前提。
- **画面重叠不等于实际在吊物下方。** 此类空间判定仍需要可信人员地面位置与吊物地面投影/外包络。二维人员框和吊物框相交只能作风险候选。
- **地面映射的适用对象要明确。** 人员脚点属于地面点；悬空工件的图像中心或轮廓不能直接套用地面单应矩阵得到真实地面位置。若要比较米制距离或物理方向，需要标定和经验证的载荷几何映射。
- **检测质量优先影响业务结果。** 已标注验证集上，当前预训练模型在固定阈值下的人员召回较低，跟踪不能可靠补回长时间没有检测证据的人员。后续应先改善检测，再验证事件逻辑；单纯增加完整 MOT 标注不会自动改善检测模型。

## 5. 当前阶段应标哪些数据

已完成的静态人员框继续用于检测器适配。为明确是否能判定同时运动/伴行，建议在代表性连续片段增加：

| 标签 | 用途 |
|---|---|
| 工件悬吊/非悬吊、移动/静止、摆动/升降、不可判定及起止时刻 | 验证吊物状态与真实运动判断。 |
| 人员移动/静止/不可判定及涉事人员 | 验证是否有人实际移动，而不仅是出现。 |
| 人随吊物伴行/独立行走/横穿/人员静止而吊物经过，及事件起止时刻 | 直接评价业务事件，不把所有同时运动都标为伴行。 |
| 涉事人员与工件的框/轮廓和短时 ID、遮挡状态 | 核验目标配对和事件连续性。 |
| 相机/大车/小车运动情况及画面质量 | 区分目标运动与镜头运动，定位不可判定原因。 |

第一阶段可以先标事件和涉事目标，并在关键连续片段上补足短时身份对应。若以后要报告完整 IDF1/HOTA，则所选测试片段中的所有有效人员仍应按统一规则逐帧标框和 ID，并处理忽略区域，不能用只标涉事对象的片段直接计算全场跟踪指标。

前面的 [人员持续跟踪数据标注指南](人员持续跟踪数据标注指南.md) 适用于完整轨迹标注与评估；本阶段可以按上表逐步准备业务验证数据，不必先把全部录像都制作成 MOT 数据集。

## 6. 当前建议

对于现有方案 B5，采用“**人员检测 + 工件定位/状态 + 相机运动估计 + 事件窗内短时关联 + 配对运动规则**”。保留当前轻量 BoT-SORT 作为人员对应工具，优先解决人员检测漏检和吊物运动证据，再用连续片段验证伴行事件。

如果最终业务仅要求“吊物移动时风险区有人”，可先实现区域事件版本，采用逐帧检测和时序状态；其输出名称和验收规则应与 B5 的伴行判定区分清楚。
